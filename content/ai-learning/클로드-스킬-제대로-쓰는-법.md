클로드 스킬을 "멋있어 보여서" 깔아만 두고 한 번도 안 써 본 적 있다면, 이 글이 도움이 된다. 스킬이 정확히 무엇이고, 어떻게 쓰고, 어디에 응용할 수 있는지, 그리고 실제로 꾸준히 쓸 만한 스킬은 뭐가 있는지 정리했다.

## 개요

**스킬**은 클로드가 작업을 시작하기 전에 먼저 읽는 작업 지침서다. 코드, 문서, PPT 등 무엇을 만들든 클로드는 그때그때 그럴듯한 결과를 내놓지만, 아무 기준이 없으면 결과물이 매번 들쭉날쭉하다. 어떤 날은 장황하고, 어떤 날은 형식이 깨지고, 어떤 날은 평소 쓰던 문체와 전혀 다른 글이 나온다.

스킬을 만들어 두면 클로드가 작업 전에 "이 순서로 진행해라", "이 문체를 따라라", "이 형식을 지켜라" 같은 규칙을 먼저 읽고 시작한다. 그래서 스킬은 기능을 더해 주는 **플러그인**이라기보다, 클로드에게 **내가 일하는 방식을 가르쳐 주는 문서**에 가깝다.

다만 현실적으로는, 처음엔 신기해서 이것저것 다 설치하지만 며칠 지나면 손이 안 가는 스킬이 대부분이다. 기능은 화려한데 실제 작업 흐름에 붙지 않기 때문이다. 결국 오래 살아남는 스킬은 화려함보다, 매일 반복하는 일을 실제로 줄여 주고 작업 방식 자체를 바꿔 주는 스킬이다.

## 사용법

스킬을 쓰는 방법은 크게 세 갈래다.

**1) 저장소 링크로 설치하기**
스킬은 대개 마크다운 파일이나 작은 패키지 형태로 공개되어 있다. 저장소 링크를 복사해서 클로드(클로드 코드)에게 붙여넣고 "이 스킬을 설치해 줘"라고 요청하면, 클로드가 알아서 받아 적용한다.

**2) CLAUDE.md에 통합하기**
코딩 원칙처럼 프로젝트 전체에 항상 적용되길 바라는 규칙은, 프로젝트 루트의 `CLAUDE.md` 파일에 넣어 두면 좋다. "이 가이드라인을 읽고 CLAUDE.md를 보강해 줘"라고 요청하면, 프로젝트를 열 때마다 클로드가 자동으로 그 내용을 먼저 읽는다.

**3) 스킬 마켓플레이스에서 찾기**
어떤 스킬이 있는지, 내 작업에 맞는 스킬이 뭔지 감이 안 올 때는 스킬을 모아 둔 전용 사이트에서 둘러보고 다운로드할 수도 있다. 필요한 스킬을 설명만 하면 알아서 찾아 설치해 주는 "스킬 찾기" 전용 스킬도 있다.

**관리 원칙 한 가지.** 스킬은 켜져 있는 동안 클로드의 작업 공간(컨텍스트)을 차지한다. 그러니 무작정 많이 설치하기보다, 실제로 반복해서 쓰는 몇 개만 남기고 정리하는 쪽이 결과물 품질에 더 낫다.

## 응용 분야

| 상황 | 스킬이 해결해 주는 것 |
|---|---|
| 버그 하나 고쳐 달랬더니 멀쩡한 코드까지 깨짐 | 요청 범위 밖은 건드리지 않도록 원칙을 강제 |
| 기능을 바로 구현시켰더니 엉뚱한 곳에서 터짐 | 계획 → 테스트 → 구현 → 리뷰 순서를 강제해서 품질을 높임 |
| 클로드가 만든 화면이 딱 봐도 "AI가 만든 티"가 남 | 뻔한 색상·레이아웃 패턴을 금지 목록으로 걸러냄 |
| 남이 짠 코드나 오픈소스를 분석하느라 시간을 다 씀 | 프로젝트 구조를 한눈에 보이는 지도로 정리해 줌 |
| 세션이 바뀔 때마다 같은 맥락을 매번 다시 설명함 | 중요한 결정과 선호를 기억해 뒀다가 다음 세션에 불러옴 |
| 유튜브 영상을 분석하고 싶은데 제목·설명만 읽힘 | 영상의 장면과 자막을 함께 분석해 구조를 파악 |
| 내가 쓴 글에서 AI 특유의 문체가 티 남 | AI스러운 표현을 걸러내고, 내 문체를 학습해 다시 씀 |

## 추천 스킬 (유튜브)

아래는 클로드를 오래, 많이 써 온 한 유튜버가 수십 개를 설치해 보고 실제로 꾸준히 쓰고 있다고 소개한 스킬들이다. 정확한 설치 링크는 영상이나 스킬 이름으로 검색해 최신 버전을 확인하는 것을 권한다.

| 스킬 | 하는 일 |
|---|---|
| **Karpathy Guidelines**(카파시 가이드라인) | 모르면 먼저 묻고, 불필요하게 복잡하게 만들지 않고, 요청 범위 밖은 건드리지 않는다는 코딩 원칙을 `CLAUDE.md`에 심어 준다. |
| **Superpowers**(슈퍼파워) | 바로 코드를 짜는 대신 요구 사항 정리 → 구현 계획 → 테스트 → 구현 → 코드 리뷰 순서를 강제해 완성도를 끌어올린다. |
| **Frontend Design**(프론트엔드 디자인) | 앤트로픽이 공식으로 낸 스킬로, 전형적인 "AI스러운" 폰트·배경·레이아웃을 금지 목록으로 걸러낸다. |
| **Understand**(언더스탠드) | 프로젝트 전체를 스캔해서 파일·함수·의존성 관계를 지도(지식 그래프)로 정리해 준다. 낯선 코드베이스를 파악할 때 유용하다. |
| **Agent Memory**(에이전트 메모리) | 중요한 결정과 작업 맥락을 조용히 기록해 뒀다가, 다음 세션에 관련된 기억만 골라서 불러온다. |
| **Claude Video**(클로드 비디오) | 영상을 다운로드해 프레임과 자막을 함께 분석한다. 영상의 구조나 초반 전개를 파악할 때 쓴다. |
| **Humanizer**(휴머니저) | AI 특유의 문체 패턴을 찾아 고치고, 내가 쓴 글 샘플을 주면 그 문체에 맞춰 다시 써 준다. |
| **Find Skills**(파인드 스킬즈) | "이런 작업에 좋은 스킬 찾아 줘"라고 요청하면 필요한 스킬을 스스로 탐색해 설치해 준다. |

## 마무리

클로드를 잘 쓰는 사람은 매번 프롬프트를 정교하게 쓰는 사람이 아니라, 자기 작업 방식을 스킬로 구조화해서 도구 안에 저장하고 계속 다듬어 가는 사람이다. 같은 시간을 들여도 누군가는 매번 같은 지시를 반복하고, 누군가는 이미 만들어 둔 스킬로 바로 결과를 뽑는다. 이 차이는 생각보다 빨리 쌓인다.
