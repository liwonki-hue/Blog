매일 아침 정해진 시각에 클로드가 알아서 증권 시세와 관련 뉴스를 정리해서, 카카오톡과 지메일로 보내 주는 시스템을 만든다. 코딩은 한 줄도 몰라도 된다.

## 원리

클로드 혼자서는 대화만 할 뿐, 카카오톡을 보내거나 메일을 발송하는 등 외부 세계에 직접 손을 댈 수 없다. 이걸 가능하게 하려면 두 가지가 필요하다.

- **커넥터** — 클로드와 카카오톡, Gmail, 증권 정보 서비스 같은 외부 도구를 이어 주는 연결 고리.
- **MCP**(Model Context Protocol) — 그 연결이 실제로 작동하는 표준 규격. 서비스마다 제각각 다른 연동 방식을 쓰던 걸, 하나의 공통 규격으로 통일해 놓은 것이다. 범용 충전 단자가 기기마다 다른 케이블을 쓰지 않아도 되게 해 준 것과 비슷하다. 이 규격 덕분에 클로드는 어떤 새 서비스가 추가되더라도 같은 방식으로 연결할 수 있다.

"증권 정보를 카카오톡으로 보낸다"는 작업은 사실 이렇게 세 단계로 쪼개진다.

1. 증권 정보 MCP로 오늘 시세·뉴스를 조회한다.
2. 클로드가 그 결과를 읽기 좋게 정리한다.
3. 카카오톡 MCP(또는 Gmail 커넥터)로 정리된 내용을 전송한다.

여기에 **예약 실행** 기능을 더하면, 매번 사람이 "브리핑해 줘"라고 말하지 않아도 정해진 시각에 이 세 단계가 자동으로 돌아간다.

## 구조

```
[예약 스케줄]  매일 지정한 시각(예: 오전 7시)
      │
      ▼
[클로드 데스크톱 자동화]  저장해 둔 "증권 브리핑" 스킬을 실행
      │
      ├─► [증권 정보 MCP]   국내·미국 시세, 주요 뉴스 조회
      │
      ▼
[클로드가 내용을 정리]  보기 좋은 브리핑 형태로 요약
      │
      ├─► [카카오톡 MCP]    "나에게 채팅"으로 전송
      │
      └─► [Gmail 커넥터]    같은 내용을 메일로 전송
```

각 MCP·커넥터는 독립된 부품이라, 필요에 따라 빼거나 더할 수 있다. 예를 들어 슬랙 MCP를 하나 더 연결하면 같은 브리핑을 슬랙으로도 받을 수 있다.

## Setting 방법

**1) 클로드 데스크톱 앱 준비**
클로드 데스크톱 앱을 설치하고 로그인한다. 예약 자동 실행 기능은 데스크톱 앱에서만 쓸 수 있다.

**2) 증권 정보·카카오톡 MCP 연결 (PlayMCP)**
1. 카카오에서 제공하는 PlayMCP 사이트에 접속해 카카오 계정으로 로그인한다.
2. 도구함에서 **카카오톡 나에게 채팅**, **증권 정보**(국내·미국), 필요하면 **뉴스 검색** MCP를 찾아 추가한다.
3. 클로드 앱의 대화창에서 커넥터 추가 메뉴를 열고 **PlayMCP**를 검색해 연결한다.
4. 연결된 PlayMCP 항목의 스위치를 켜서 활성화한다.

**3) Gmail 커넥터 연결**
클로드 설정의 커넥터 메뉴에서 Google 계정으로 **Gmail**을 연결하고, 메일 발송 권한을 승인한다.

**4) 연결 확인**
대화창에 "오늘 주요 증시 뉴스 알려 줘" 같은 테스트 프롬프트를 입력해, MCP가 실제로 정보를 가져오는지 먼저 확인한다.

## 사용 방법

**1) 원하는 브리핑 형식으로 요청하기**

```text
매일 아침 브리핑용으로 아래 내용을 정리해 줘.

1. 국내·미국 주요 지수 현재가와 전일 대비 등락
2. 내가 관심 있는 종목(예: ○○○, ○○○)의 시세와 관련 뉴스 1~2건
3. 오늘 알아 둘 만한 증시 이슈 한두 가지

간결하게 카카오톡 메시지 하나로 보낼 수 있는 분량으로 정리해 줘.
```

**2) 재사용 가능한 스킬로 저장하기**
결과가 마음에 들면 "방금 나눈 대화 내용을 스킬(또는 플러그인)로 만들어 줘"라고 요청한다. 그러면 같은 작업을 짧은 명령어 하나로 다시 실행할 수 있게 저장된다.

**3) 예약 작업 등록하기**
예약 작업 메뉴에서 새 예약을 만들고 다음을 지정한다.

| 항목 | 설정 값 예시 |
|---|---|
| 반복 주기 | 매일 |
| 실행 시각 | 오전 7시 |
| 실행 내용 | 저장해 둔 브리핑 스킬 명령어 |
| 실행 방식 | 승인 없이 바로 실행 |

**4) 주의할 점**
- 예약 작업은 **컴퓨터가 켜져 있을 때만** 실행된다. 지정한 시각에 컴퓨터가 꺼져 있으면 그날은 건너뛴다.
- 처음 며칠은 "승인 없이 바로 실행"을 끄고, 결과를 사람이 한 번씩 확인한 뒤 자동 전송으로 바꾸는 쪽이 안전하다.
- 카카오톡·Gmail 계정을 연결하는 작업이라, 개인 계정으로 로그인된 내 컴퓨터에서만 설정한다.

## 응용 분야

같은 구조(예약 → MCP 조회 → 정리 → 전송)를 그대로 재활용하면 증권 정보 외에도 다양하게 응용할 수 있다.

- **일정 브리핑** — 오늘 일정과 할 일을 아침마다 요약해서 전송
- **업무 보고서 자동 발송** — 주간 실적이나 진행 상황을 정리해 메일로 자동 발송
- **뉴스 모니터링** — 관심 키워드나 경쟁사 관련 뉴스를 매일 체크해 알림
- **고객 문의 요약** — 쌓인 문의를 정리해서 담당자에게 메일로 전달
- **사내 데이터 알림** — 재고·매출 같은 사내 시스템에 MCP를 연결하면 같은 방식으로 자동 리포트 가능
- **전송 채널 확장** — 슬랙, 팀즈 등 다른 메신저용 MCP를 추가로 연결하면 같은 브리핑을 여러 채널에 동시에 보낼 수 있다

증권 정보는 참고용 브리핑이며, 실제 투자 판단은 원문 데이터와 본인 책임 아래 확인하고 결정하는 것이 안전하다.
