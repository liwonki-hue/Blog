# Context Notes

## 2026-09-25
- 자막은 yt-dlp로 받은 YouTube 자동 생성 한국어 자막이다. 인명·용어 오인식이 많아(예: 오븐 노노르=Novum Organum, 바스칼=파스칼, 휴=흄) 일반 표기로 바로잡았다.
- 영상은 여러 편의 짧은 강의를 이어 붙인 구성이다. 순서는 베이컨, 홉스, 데카르트, 파스칼, 로크, 스피노자, 라이프니츠, 버클리, 볼테르, 흄, 루소, 애덤 스미스, 칸트(순수·실천·판단력), 트롤리 딜레마, 피히테, 슐라이어마허, 셸링, 헤겔, 쇼펜하우어, 밀, 다윈, 키르케고르, 마르크스, 퍼스, 제임스, 니체이다(총 25명).
- 글은 시대 흐름 기준으로 묶어 재배열했다(과학혁명, 경험론과 합리론, 계몽, 칸트, 독일 관념론, 19세기, 실용주의, 니체). 영상 순서를 그대로 따르지 않은 이유는 독자가 흐름으로 읽기 쉽게 하기 위해서다.
- 영상 표현과 일반 표기가 다른 곳은 본문에 병기했다(키르케고르 "심리적 실존"은 통상 "심미적 실존").
- 볼테르의 "나는 당신의 의견에 동의하지 않지만..." 문장은 영상에서도 이블린 홀이 쓴 말로 소개하므로 그 취지를 적었다.
- 영상은 강의자의 해석이 섞여 있다(예: 니체 영원회귀는 가정법, 피히테 해석). 본문은 영상의 설명을 따르되 "영상에서는" 표현으로 출처를 밝혔다.
- 메뉴 개편(철학 일기/투자 일기/독서 일기)은 글 작성과 별개의 논리적 변경이라 먼저 별도 커밋으로 분리한다.
- 폴더명(philosophy, finance)과 URL은 바꾸지 않았다. 표시 이름만 변경한 것이라 기존 permalink를 유지한다.
